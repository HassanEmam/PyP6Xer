xerparser.model.classes.xer_table

Generic storage for XER tables that have no dedicated model class.

PyP6Xer models the commonly used P6 tables with typed classes. Every other table in an export (PROJCOST, WBSSTEP, TASKMEMO, …) used to be silently dropped on read. XerTable/XerTables preserve those records losslessly — original headers, column order and row values — and expose them with dict- and attribute-style access, so a parse followed by a write round-trips any table the library has no typed model for.

find_by_id(id)[source]

Best-effort lookup by the table’s own id column.

Uses the header that matches the table name when present (e.g. wbs_step_id for WBSSTEP), otherwise the most plausible non-foreign-key *_id column. Returns None when the table has no usable id column (e.g. TASKFDBK) or no record matches.
